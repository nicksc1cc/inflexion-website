AI citations come from places your media plan does not control.

The useful question is not only which page a model retrieves. It is which sources make the answer believable.

The source map comes before the content calendar

Many AI visibility programmes start with a question set and end with a list of pages to publish. Start with the evidence instead. Find out which domains answer engines already cite for the questions that matter.

Recent source analyses repeatedly surface Reddit, Wikipedia, YouTube, LinkedIn, news sites and specialist reviews. The exact order changes by engine and category. The consistent finding is that a brand's website is only one part of the evidence available to a model.

Peec AI's analysis of 30 million sources found Reddit, YouTube, LinkedIn, Wikipedia and Forbes among the most-cited domains across ChatGPT, Google AI Mode, Gemini, Perplexity and AI Overviews. In the same period, ProFound's 680 million-citation dataset showed different platform patterns: Wikipedia accounted for 7.8 percent of ChatGPT citations, Reddit 6.6 percent of Perplexity citations and Reddit 2.2 percent of Google AI Overviews citations.

Those percentages are distributions within particular datasets, not ordinary media market share. The narrower conclusion is useful: the source mix changes with the question and the engine.

Parse's 2026 analysis also placed YouTube, Reddit and Wikipedia near the top of the multi-platform source mix. A separate analysis reported by Everything-PR examined more than 680 million citations and found a concentrated distribution, with a small number of domains accounting for a large share. Treat the figures as directional. Source choice still shapes visibility.

Reddit is evidence with context attached

Reddit contains first-hand experience, product comparisons and language that brand sites rarely publish. It is difficult to influence because credibility comes from the conversation, not from a paid placement.

A cited thread has an author, a comment history and moderation rules. Copying a polished brand answer into a subreddit can do more harm than good. The useful work starts with listening, finding questions that are already being discussed and contributing information that can stand without a sales pitch.

The measurement needs the same care. A brand mention in Reddit is not equivalent to a link from a trade publication. Both may influence an answer, but they carry different context and different risks. A single citation count hides that distinction.

Wikipedia sits in a wider evidence chain

Wikipedia is frequently cited because it gives models a structured, sourced account of an entity. It is also one of the least controllable places in a communications plan.

The answer is not promotional copy for an encyclopaedia. Make the underlying evidence easier to verify: independent coverage, clear company facts, consistent naming and sources that can be checked by somebody with no commercial interest in the outcome.

This is where earned media and technical work meet. Coverage that names an organisation without explaining what it does gives a model little to use. A factual article, a maintained company profile and a consistent entity footprint create a stronger retrieval path.

Build the plan from the source map

  1. Run the buyer prompt set across the engines your audience uses.
  2. Record the domains cited in each answer, including community and video sources.
  3. Separate sources you can pitch from sources you can influence only indirectly.
  4. Map the factual gaps that make your brand difficult to describe accurately.
  5. Track changes in source mix, not only whether the brand was mentioned.

The result is more useful than a generic PR target list. It says which sources matter for which questions, what evidence each source accepts and where the brand can participate without manufacturing a conversation.

Review the map against the buying questions

Source choice should be reviewed against the questions that create commercial pressure. A category question may draw on Reddit and specialist reviews. A comparison may lean on YouTube, trade coverage or a retailer page. An entity question may depend on Wikipedia and consistent company facts.

Run the same prompt set again after a material change in the category, the product or the search system. Record which domains entered or left the answer, whether the brand's position changed and what language the source contributed.

That record gives content, PR and technical teams a shared worklist. The decision is no longer where the brand should publish in general. It is which evidence each important answer needs, who can improve it and how the next collection will show the change.
