# Inflexion / Massaman operating rules

This repository is worked on by Massaman. These rules are delivery gates, not suggestions.

## Skill routing

For visual or frontend work, load and follow:

- `project-massaman`
- `project-inflexion`
- `frontend-design-judgement`
- `massaman-design-operations`

For charts, diagrams, maps, data visuals or visual storytelling, also load `massaman-visual-reference-library` and read `/Volumes/My Passport/.hermes/profiles/massaman/visual-library/` before implementation. Use the award catalogue, chart-selection checklist and visual review rubric.

For copy changes, load `ai-copywriter` and `humanizer` before editing prose. Preserve supplied copy unless the user explicitly requests copy changes.

## Required workflow

1. Inspect the repository, route, design authority, tokens and existing components before editing.
2. Record the target files, copy policy, visual scope and non-goals before implementation.
3. Prefer targeted patches. Do not replace a whole page for a local design change.
4. Run the Massaman orchestrator doctor before meaningful work:

```bash
node "/Volumes/My Passport/.hermes/profiles/massaman/orchestrator.mjs" doctor
```

5. Run the route verification gate before delivery. Never append `|| true` to this command:

```bash
cd "/Volumes/My Passport/.hermes/profiles/massaman/qa-runner"
npm run qa -- --project inflexion --route <route> --base-url http://127.0.0.1:8180 --start-server --server-command "python3 -m http.server 8180" --server-cwd "/Users/nicholaschristensen/Projects/04-inflexion/08-Website" --out /tmp/massaman-verify --browsers chromium,firefox,webkit --viewports 375,768,1024,1440 --full-page --design-review
```

6. A non-zero QA result blocks delivery. Screenshots captured with axe, console, link, interaction, overflow or structural failures are not a pass.
7. Inspect rendered screenshots at mobile and desktop widths. Do not infer visual quality from source code.
8. Verify the deployed URL after any push. Local evidence is not live evidence.

## Design authority

Use `assets/design-system/DESIGN.md` and `assets/design-system/tokens-built.css` as the source of truth. Preserve the editorial monochrome system, restrained orange accent and blue data accent. Keep visual elements unless the user explicitly asks to remove them.

## Delivery claim

Never say a page is fixed, complete or deployed unless the result, route, browser matrix and live URL have been verified. Report known axe or visual issues instead of waiving them silently.
